# Hybrid B-Spline + AES Image Encryption

Research implementation of image encryption using a key-dependent discrete B-spline pixel permutation, reversible nonlinear bidirectional diffusion, and AES-128-CBC. Domain-separated HKDF-SHA256 derives material from a 256-bit master key. Normal encryption generates a fresh random IV.

## Run in Google Colab

[Open the notebook in Colab](https://colab.research.google.com/github/Ay9man/hybrid-bspline-aes-image-encryption/blob/main/hybrid_bspline_aes.ipynb)

This repository is private. The direct link requires Colab to have access to your GitHub repository. If it cannot open the notebook, use the upload method below; the repository can remain private.

1. Download `hybrid_bspline_aes.ipynb` from this repository, or use the copy in your local Project Code folder.
2. Open [Google Colab](https://colab.research.google.com/) and use **File > Upload notebook** to select the notebook.
3. Connect to a Python runtime. The code uses CPU libraries; a GPU is not required.
4. Run the first cell to install dependencies, then run the second cell to execute the experiment. You can also use **Runtime > Run all**.
5. View plots and tables below the experiment cell. Download the generated CSV files from the Files sidebar before the runtime is deleted. Save a notebook copy to Google Drive if you want to retain notebook edits and outputs.

For an initial short check, change `NUM_IMAGES = 1` and `DIFF_TRIALS = 2` in the Configuration section before running the experiment. Restore the intended settings for research results.

The notebook automatically downloads BSDS500 through kagglehub. Default settings process 10 grayscale images resized to 256 x 256, with 100 differential trials per image.

## Run locally

Use Python 3.10 or newer in a virtual environment:

```sh
python -m pip install -r requirements.txt
python hybrid_bspline_aes.py
```

Run from a dedicated working directory: the experiment writes CSV results into the current directory and displays plots. Internet access is required for the initial dataset download.

## Configuration and outputs

Edit the Configuration section to change `IMAGE_SIZE`, `NUM_IMAGES`, `DIFF_TRIALS`, or `MASTER_KEY_HEX`. A fresh 256-bit master key is generated by default; only its fingerprint is printed. Keep any reproducibility key private and do not commit it.

The experiment generates main metrics, differential trial and summary tables, key-sensitivity tables, overall summaries, and an ablation table. The final block reports differential outliers. CSV results are excluded by `.gitignore`.

AES-CBC provides confidentiality without authentication. This is a research experiment.
