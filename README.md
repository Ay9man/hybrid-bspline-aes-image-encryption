# Hybrid B-Spline + AES Image Encryption

Research implementation derived from `full code.txt`.

The pipeline uses a key-dependent discrete B-spline pixel permutation, reversible nonlinear bidirectional diffusion, and AES-128-CBC. Domain-separated HKDF-SHA256 derives material from a 256-bit master key. Normal encryption generates a fresh random IV.

## Files

- `full code.txt`: original source, preserved unchanged.
- `hybrid_bspline_aes.py`: Python version; the Colab installation command is moved to requirements.txt.
- `hybrid_bspline_aes.ipynb`: notebook with an installation cell and the complete experiment.
- `requirements.txt`: dependencies from the original installation command.

## Run locally

Use Python 3.10 or newer in a virtual environment:

```sh
python -m pip install -r requirements.txt
python hybrid_bspline_aes.py
```

Run from a dedicated working directory: the experiment writes CSV results into the current directory and displays plots. It downloads the BSDS500 dataset through kagglehub and uses 10 grayscale images resized to 256 x 256 by default, with 100 differential trials per image. Internet access is required for the initial dataset download.

## Run in Colab

Upload `hybrid_bspline_aes.ipynb` to Google Colab and run the cells in order.

## Configuration and outputs

Edit the Configuration section to change IMAGE_SIZE, NUM_IMAGES, DIFF_TRIALS, or MASTER_KEY_HEX. A fresh 256-bit master key is generated by default; only its fingerprint is printed. Keep any reproducibility key private and do not commit it.

The experiment generates main metrics, differential trial and summary tables, key-sensitivity tables, overall summaries, and an ablation table. The final block reports differential outliers. CSV results are excluded by .gitignore.

AES-CBC provides confidentiality without authentication. This is a research experiment. The original source notes that results must be regenerated for this nonlinear diffusion version before updating paper tables.

## Validation

The Python source was checked for syntax and the notebook structure was checked. The complete dataset experiment has not been run during project packaging. Existing permutation and nonlinear diffusion inverse self-tests remain in the source.
